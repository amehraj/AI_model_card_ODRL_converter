Audio2Emotion (A2E): speech emotion recognition (SER) classifier embedded in the Audio2Face-3D microservice; six emotions (anger, disgust, fear, joy, neutral, sadness); Wav2Vec2 (Wav2Vec2-Large-LV60), 3.1 x 10^8 parameters; Transformer; input raw float32 audio, output float32 class probabilities; NeMo 1.0.0; Ampere/Blackwell/Hopper/Lovelace/Pascal/Turing; Linux; release 08/27/2025; version v2.1 TensorRT engine.
License: License Agreement for NVIDIA Audio2Emotion Model for Use with Audio2Face Project. Only for use in connection with the NVIDIA Audio2Face project; not outside it; not for the purpose of emotion recognition. Ready for commercial/non-commercial use. Deployment geography: global.
Use case: converting speech audio into emotional states that drive realistic 3D facial animations within Audio2Face; not intended for standalone emotion recognition or general-purpose audio analysis.
Versions: v1.0 wav2vec2-base, 80% accuracy; v2.0 fine-tuned from wav2vec2-large-lv60 (not trained on EMO-DB, Emozionalmente, TTS GPT 4o); v3.0 same checkpoint as v2.0, trained on small chunks.
Training: audio, less than 10,000 hours, 30029 samples (internal, RAVDESS, CREMA-D, JL Corpus, EMO-DB, Emozionalmente, TTS GPT 4o, Lindy & Rodney); automated collection, human labeling. Testing and evaluation: internal crowdsourced dataset, 1350 samples each.
Inference: TensorRT; T4, T10, A10, A40, L4, L40S, A100, RTX 6000 Ada, A6000, Pro 6000 Blackwell, RTX 3080/3090/4080/4090/5090.
Ethical: trustworthy AI shared responsibility; developers work with internal model team to ensure requirements met; bias, explainability, safety and security, privacy in Model Card++ subcards (not accessible). Integration requires additional testing with use-case-specific data (V-model).
